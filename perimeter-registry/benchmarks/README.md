# Benchmark material status

There is no active or agent-visible retrieval benchmark in this directory.
The completed July 2026 studies are quarantined under [`historical`](historical)
so their frozen inputs, outputs, scoring, and provenance remain auditable.

Those studies compared fresh source research with **pre-resolved scope assistance**. The assisted arm could read curated registry fixtures and
deterministic resolver output containing the identity, perimeter, identifier,
caveat, and source facts needed to answer the questions. They therefore did not
measure end-to-end financial retrieval and must not be presented or reused as a
fair retrieval comparison.

See [`BOUNDARY.md`](BOUNDARY.md) before using any registry or historical study
material in an evaluation. A redesigned benchmark and any new agent input packet
require separate approval.
